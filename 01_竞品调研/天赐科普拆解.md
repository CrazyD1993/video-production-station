# 竞品拆解：天赐科普

## 可复刻的底层模型

`熟悉事物 + 陌生后果 + 强视觉主体 + 可信背书 + 生活落点 + 自然争议`

## 高互动现象

- 生活风险类会把“我每天都在做”的行为，改写为“原来有后果”的问题，例如美甲灯、食物、台风。
- 动物和假设实验类依靠明确主体、巨大尺度和反差画面获取点击。
- 评论区不是硬提问，而是让用户自然追问“那我应该怎么办”“我这里会不会受影响”。

## 本项目的差异化选择

- 用更清楚的事实边界替代纯恐吓：先给结论，再解释“有用到什么程度”。
- 每条灾害内容都以官方实时预警为准，不制造具体地区焦虑。
- 把可执行的家庭准备动作作为收藏理由，而不是只制造恐惧。

## 选题判断

优先选择同时具备以下条件的题：

- 用户能在 3 秒内代入自己的生活。
- 能用一个强对象完成封面表达。
- 有可信来源支持一个反常识或边界结论。
- 结尾能给出 3 至 5 个不过度承诺的实用动作。
