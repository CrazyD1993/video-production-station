# Petrichor Asset Board Preview — Visual Direction

## 核心方向

**Earth Documentary / Soft Signal**：像一本潮湿的自然纪录片工作笔记，真实影像优先，机制草图只做克制解释。

## 色彩

- 背景：`#182019` 深林绿
- 主文字：`#F0EAD2` 湿纸米白
- 辅助文字：`#C8CBB9`
- 土壤强调：`#A98467`
- 苔藓强调：`#ADC178`

## 字体

- 主标题：`Songti SC`
- 镜头号、时间和状态：`Hiragino Sans GB`

## 构图与动效

- 9:16，低清 `540×960`，24fps。
- 真实素材尽量满版，只在上下边缘叠加小型审核信息。
- 转场使用 0.25 秒柔和溶解，不使用闪白、黑场、科技扫描线或夸张粒子。
- 机制 B 通过横向缓慢移动展示「困气—气泡—气溶胶」，不用大箭头。

## 明确禁止

- 不用震动弹跳文字、渐变字、HUD、新拟态卡片或蓝光实验室美学。
- 不载入锁定旁白，不做音效和音乐混音。
- 不把素材板预览伪装成完整成片。
