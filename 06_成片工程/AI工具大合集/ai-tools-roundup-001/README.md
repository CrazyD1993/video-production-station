# AI 工具大合集 001

## 项目目标

制作一条约 18-22 秒的中文竖屏短视频，用真实产品 Logo 对应真实功能，快速讲清三类 AI 内容工具：

1. 动态海报
2. 广告切片
3. 产品分解动画

本条是脱离当前科普账号定位的通用内容任务，不修改现有「雨后泥土味」项目状态。

## 当前结论

- 主产品：Adobe Express、OpusClip、FlexClip。
- 补充产品：Canva、Vizard、Meshy。
- 真实品牌 Logo 只作为本地样片图层使用，不提交 GitHub。
- 分类功能底图为 AI 原创资产，可用于本地样片。
- 用户真人口播素材尚未提供，成片门禁为：收到口播视频或本机绝对路径。
- MoneyPrinterTurbo 已部署，但自动生成仍需可用的大模型 API Key 与 Pexels API Key。

## 文件入口

- `02-口播稿与动态分镜.md`

- `assets/generated/three-category-visual-board-v1.png`
- `input/`：放置用户真人口播视频
- `output/`：输出审核样片
