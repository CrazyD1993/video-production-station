# 雨后泥土味 Alpha 收口设计

**任务：** `petrichor-alpha-finalization-001`

**批准依据：** 用户提供并要求执行的 `CHATGPT_TO_CODEX_petrichor_alpha_finalization_001.md` 是本轮已批准设计；本文只把该设计固化为实现边界，不新增创意路线。

## 交付边界

- 保持锁定的 13 镜顺序与名义时间线 `0.00–46.80`。
- 画面轨采用 CFR 24fps，共 1123 帧，轨道时长 `46.791667s`；音频与容器收口到 `46.80s`。这是 46.80 秒在 24fps 整数帧约束下的最近下取整表达。
- 锁定旁白只在开头加入 `0.20s` 静音偏移，PCM 样本不重采样、不变速、不压缩停顿。
- 复用既有临时环境声，仅做基础电平平衡；临时字幕只用于审片。
- 不调用 Seedance 或任何付费生成模型，不制作发布母版。

## 画面架构

### 真实素材

- S01 使用一条许可可核验的真实单滴撞击土壤高速素材，连续保留落下、接触、颗粒/水花或即时湿润反应。
- S05–S07 可使用一条免费合规的真实土壤纵向剖面素材作为连续母场景底层；程序动作只解释水、吸附与局部微生物苏醒，不取代真实土壤主体。
- S02、S03、S04、S08、S13 从既有合规代理素材中按限制性精修保留；S13 只做灰绿色过渡统一。

### 机制 A

- S05–S07 共用 `scene_group: mechanism_a_continuous`。
- 动作连续为：地表水沿孔隙下渗 → 少量物质随水膜移动并吸附土粒 → 局部菌丝/微生物遇水轻微苏醒。
- 禁止矩形拼贴、霓虹、科技 HUD、卡通细菌、冻结画面或大字代替动作。

### 机制 B

- S09–S11 共用 `scene_group: mechanism_b_continuous`。
- S09 以可见土壤孔隙内空气腔开始，水包围后收缩并闭合为同一个气泡。
- S10 只接入既有 G02 合格上升段，速度比例 `1.000`，几何连续。
- S11 用 2–4 帧完成薄膜破裂，释放少量细微滴，随后水面轻微回落；禁止大液柱或淡出替代破裂。

### S12 湿润

- 保留裂纹构图，湿润遮罩沿裂缝、土粒边缘与低洼区域不规则扩散。
- 只使用冷湿棕黑与克制水膜高光，完全移除橙色发光；末帧保留干湿共存。

## 声音与字幕

- 旁白轨：锁定 WAV，`adelay=200ms`，原速 `1.000`。
- 环境轨：既有临时雨后环境声，低电平循环/裁切到 46.80 秒，不做正式混音。
- 字幕：从锁定时间戳 JSON 派生，整体平移 0.20 秒；文字不改写，最多两行，底部安全区内克制白字与轻阴影。

## 可追溯性

- 清单逐镜记录素材 ID、`scene_group`、底层真实来源、派生链、原始时间码、使用时间码、速度比例、许可 URL 与证据文件。
- 同一连续机制母场景可跨镜复用，但真实底层素材的实际出现次数必须递归展开。
- 所有输出视频使用 CFR 24fps，并以逐包 PTS 差值验证连续 `1/24s`。
