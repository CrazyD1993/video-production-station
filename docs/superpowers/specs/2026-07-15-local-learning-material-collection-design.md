# 个人本地学习素材收集规则设计

## 目标

将项目的素材权限从“授权明确后才能下载或进入制作”调整为“个人本地学习阶段最大开放搜集”。后续 Agent 可以主动搜索、下载、整理、分析和内部试剪公开可访问的第三方素材，不再把商业许可或书面授权作为搜集前置门禁。

## 适用范围

本规则适用于：

- 个人本地学习与研究；
- 竞品分析和镜头拆解；
- 选题、脚本和分镜参考；
- 本地素材板、测试剪辑和非公开审核样片；
- 为寻找原始出处、无水印原版或后续授权联系人而进行的素材归档。

本规则不自动授权公开发布、商业使用、广告投放、向第三方分发或出售素材。任务一旦转为上述用途，必须重新核验具体素材的权利状态和使用条件。

## 核心规则

1. **搜集最大开放。** 只要素材通过正常公开渠道可以访问，Agent 均可搜索、下载和保存为本地候选，不要求先找到可商用许可或书面授权。
2. **授权不阻塞内部工作。** 权利状态未知的素材可以用于本地分析、素材板和内部粗剪；台账可以标记为“本地学习 / 权利待核验”，但不得因为缺少授权而停止搜集。
3. **优先寻找干净原版。** 成片式本地样片尽量采用无平台水印、无字幕烧录、无二次搬运标识的原始版本。若候选带水印，应继续寻找原始发布页、官方媒体库或无水印母版。
4. **不主动去除权利信息。** 不使用去水印、内容修复、裁切遮挡等方式故意删除或改变已有水印、作者标识、版权声明或其他权利管理信息。
5. **不突破访问控制。** 不绕过付费墙、订阅限制、DRM、加密、验证码、账号权限或平台下载限制；只使用正常可访问或平台允许的获取方式。
6. **外部素材只留本地。** 第三方原始视频、图片、音频、缓存、Cookie、账号信息和未核验素材不提交 GitHub，不写入公开中继文档。
7. **来源记录从简但不断链。** 能识别时保留原始链接、平台、作者或机构、下载日期；来源记录服务于复查、找原版和未来授权，不作为本地搜集门禁。
8. **用途变化重新过门。** 如果用户以后明确要求发布、商用、投放或分发，Agent 必须先把相关任务从“本地学习”切换为“发布使用”，再逐项处理授权、许可、署名、肖像和音乐风险。

## 项目落点

批准后同步到以下长期入口：

1. `AGENTS.md`：写入简明、强制读取的项目级默认规则；
2. `00_项目总控/素材收集与本地学习规则.md`：保存完整执行细则；
3. `00_项目总控/项目说明.md`：增加规则入口和“本地学习 / 发布使用”两阶段说明；
4. `00_项目总控/GitHub同步规则.md`：核对并补充第三方原文件不得入库的边界。

## 成功标准

- 新对话进入项目后，可以从 `AGENTS.md` 直接得知素材搜集无需预先授权；
- Agent 不再因为许可不明而拒绝搜索、下载或制作本地学习样片；
- 本地学习素材与公开发布素材的边界清楚，不互相混用；
- 不主动去除权利信息，不突破付费、DRM 或账号访问控制；
- 第三方原文件和敏感信息不会进入 GitHub。
