# 核心关键帧候选方案

每个核心关键帧提供 3 个明显不同的构图候选。本轮只审批方案与提示词，不生成图片。

通用约束：9:16，真实飞机客舱舷窗，工程可信，禁止文字/Logo/水印，禁止裂纹、爆炸、事故、恐慌人物，禁止塑料 3D 卡通质感。

## KF1 停留关键帧

### KF1-A：正面微距悬停（推荐）

小孔位于画面下三分之一中心，指尖从右侧虚焦区进入，距离孔约 2 厘米；窗外冷蓝天空，机舱内暖色反光；100mm 微距、极浅景深、真实亚克力细划痕与曲面反射。优势：问题最直接，适合手指接近的 I2V。

### KF1-B：侧逆光轮廓

相机贴近舷窗侧面，小孔形成明亮针点，指尖只有剪影；夕阳穿过多层透明材质产生真实折射。优势：更电影化；风险是小孔辨识度较低。

### KF1-C：第一人称发现

乘客坐姿 POV，窗框、机翼和云层清晰可辨，小孔被一束窄光照亮，食指从下方指向但不接触。优势：代入强；风险是主体尺寸较小。

## KF2 原理关键帧

### KF2-A：真实窗体半透明剖面（推荐）

真实舷窗占画面 80%，右半边保持实物，左半边沿曲率展开为多层透明剖面；客舱侧空气微粒经小孔进入夹层，外侧承压层出现克制的应力等高线；没有大段文字，预留四个小标签位置。优势：真实与原理同屏。

### KF2-B：沿小孔穿行的探针视角

相机像微型探针从小孔向夹层内看，前景是孔壁真实材质，远处可见弧形承压层与空气粒子流；强纵深，蓝白工程照明。优势：陌生视角强；风险是物理尺度容易失真。

### KF2-C：光学桌实验隐喻

舷窗剖面置于真实航空工程实验台，细烟流显示空气路径，压力传感器只用颜色变化不显示读数；背景有模糊机舱截面。优势：证据感强；风险是容易被误认成真实实验，必须标注“结构示意”。

## KF3 后果/反转关键帧

### KF3-A：同一窗体左右状态对照（推荐）

同一个真实舷窗被光线自然分成左右两半：左侧通道畅通、夹层清晰；右侧通道被半透明可见贴片遮住、夹层出现轻雾，压力流线变得紊乱但窗体完整。优势：不靠事故也能看懂差异。

### KF3-B：气流路径熄灭

斜侧微距，小孔附近的空气粒子路径像呼吸一样流动；遮挡层出现后路径逐段熄灭，背景轻雾增加，窗体无损。优势：适合动态；风险是粒子效果过于科幻。

### KF3-C：反转式完整承压层

前景是被遮挡的小孔和轻雾，焦点后移到仍然完整的外侧承压层，明确呈现“不是立刻爆裂”；构图从紧张转为理性。优势：直接纠正标题党预期；风险是需要后期标签帮助理解。

- KF1：A / B / C
- KF2：A / B / C
- KF3：A / B / C
