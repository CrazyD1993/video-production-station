# 事实核查：飞机舷窗小孔

## 修订结论

1. 客舱舷窗通常为多层结构，但层数、承压分工、通风与防雾方案随机型和设计而异。
2. Airbus 关联专利 US5988566A 直接描述：传统客舱窗的层间空间通过小直径孔与客舱连通，以均衡夹层与客舱压力；其所述传统结构中，外侧主窗格在正常工况承担客舱压力。
3. Airbus 关联专利 US5884865A 直接描述双层窗、夹层和靠近内层窗格底部的通风孔，也指出含水汽客舱空气可能通过孔进入夹层并凝结。因此“小孔本身普遍负责减少结露”不能作为通用结论。
4. Bombardier 专利 EP3569495A1 讨论了双层或三层、通风孔、密封干燥气体和可变容积密封夹层等方案，进一步证明不同飞机不能套用同一精确剖面。
5. “短暂挡住就会立刻爆裂”没有直接技术依据，禁止进入脚本或画面。

## 技术来源

- [Airbus Operations / US5988566A — Aircraft window construction](https://patents.google.com/patent/US5988566A/en)：直接描述双窗格、外侧主窗格、内侧辅助窗格以及夹层通过小直径孔与客舱压力均衡。
- [Airbus Operations / US5884865A — Non-fogging aircraft window arrangement](https://patents.google.com/patent/US5884865A/en)：直接描述双层客舱窗、夹层、内侧窗格附近的 ventilation hole，以及专门的水汽冷凝/干燥通道。
- [Bombardier / EP3569495A1 — Aircraft cabin window sealed enclosure](https://patents.google.com/patent/EP3569495A1/en)：讨论双层/三层、通风孔、密封干气与压力变化下的替代结构。
- [14 CFR §25.775](https://www.ecfr.gov/current/title-14/section-25.775)：支持运输类飞机窗的结构安全要求，不直接解释小孔。
- [FAA Pilot’s Handbook of Aeronautical Knowledge](https://www.faa.gov/regulations_policies/handbooks_manuals/aviation/phak)：支持增压客舱与外界压差的基础原理，不直接解释舷窗构造。
- [Smithsonian 专家解释](https://www.smithsonianmag.com/smart-news/what-tiny-hole-airplane-window-does-180957867/)：作为二手补充，不覆盖制造商专利。
