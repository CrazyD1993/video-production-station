# 推荐方向脚本

目标：40—43 秒，9:16。  
方向：结构拆解科普 + 微距悬疑开场。

| 时间 | 旁白 | 画面功能 |
|---|---|---|
| 0—3 秒 | 飞机窗户上这个小孔，为什么偏偏要留着？ | 小孔微距，指尖接近但不接触；第一秒看清主体 |
| 3—8 秒 | 因为你看到的舷窗，根本不只是一层。 | 真实舷窗沿深度分层，保留真实材质与曲率 |
| 8—14 秒 | 飞到高空后，客舱里的气压会高于外面的空气。 | 机舱侧与高空侧用空间和粒子密度表达，不用大字卡 |
| 14—22 秒 | 在典型设计里，这个小孔让特定夹层和客舱侧连通，让主要压差按设计落在承压层上。 | 空气经小孔进入夹层，压力箭头转移到外侧承压层 |
| 22—29 秒 | 它也给水汽留了一条路，帮助减少夹层里的结露。 | 同一舷窗一侧清晰、一侧轻微雾气的结构对照 |
| 29—36 秒 | 如果把通道长期遮住，受影响的是这套压力和水汽管理——不是“碰一下窗户就会爆”。 | 明确写“结构示意”，气流路径变暗，雾气积聚；不出现破裂 |
| 36—43 秒 | 所以它不是瑕疵，是舷窗结构的一部分。下次坐飞机可以找找看，但别触碰或遮挡机舱设施。 | 回到真实机舱，手指收回，云层掠过，结论落在观察动作上 |

## 字幕原则

- 一屏最多 12—16 个汉字，关键词分两行；不逐字重复所有旁白。
- 结构标签只保留：`客舱侧`、`空气通道`、`承压层`、`结构示意`。
- 不出现“堵住=爆裂”“一碰就危险”等误导性大字。
