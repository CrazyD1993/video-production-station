# 04 人工审批流程

## 三道硬门禁

### Gate 1：故事板

用户需要确认：

- 推荐方向是否成立；
- 5—7 个镜头是否都有明确视觉主体和叙事功能；
- “结构示意”是否没有伪装成真实事故；
- 35—45 秒节奏是否合适。

未通过：只修改脚本、故事板和提示词，不生成图片或视频。

### Gate 2：核心关键帧

用户分别从 KF1、KF2、KF3 的 A/B/C 候选中各选一个。候选先审批提示词与构图；只有 Provider 可用或用户明确要求手动生成时，才进入图片生成。

未通过：不调用 Seedance，不批量生成关键帧。

### Gate 3：Seedance 镜头

逐镜头检查：主体一致、运动合理、画面无伪字、时长正确、结构示意标识清晰、没有事故拟真误导、无版权问题。

未通过：仅重做失败镜头，不进入完整合成。

## 状态机

```text
draft
→ storyboard_awaiting_human
→ keyframes_awaiting_human
→ seedance_handoff_ready
→ seedance_clips_awaiting_human
→ compose_ready
```

本轮允许的终态：`storyboard_awaiting_human`。  
本轮禁止的状态：`compose_ready`、`rendered`、`published`。
