# 04 人工审批流程

## 四道硬门禁

### Gate 0：参考视频

`incoming/reference-videos/` 中必须存在 REF01、REF02、REF03 三条本地视频，并由 OpenMontage 实际完成 transcript、pacing、scenes、keyframes、style、hook 与 retention mechanics 拆解。

未通过：C+A 创意方向保持未批准；不生成关键帧或 Seedance 视频。

### Gate 1：故事板

用户需要确认：

- 推荐方向是否成立；
- 5—7 个镜头是否都有明确视觉主体和叙事功能；
- “结构示意”是否没有伪装成真实事故；
- 35—45 秒节奏是否合适。

未通过：只修改脚本、故事板和提示词，不生成图片或视频。

### Gate 2：核心关键帧

纯文字提示词不能作为最终审批对象。每个核心镜头只生成两个明显不同的真实图片候选，共六张；Codex 检查后生成 2×3 联系表，用户看图为 KF1、KF2、KF3 各选一张。Codex 不代替用户选择。

未通过：不调用 Seedance；只定向重做失败候选，不扩增为九张近似图。

### Gate 3：Seedance 镜头

逐镜头检查：主体一致、运动合理、画面无伪字、时长正确、结构示意标识清晰、没有事故拟真误导、无版权问题。

未通过：仅重做失败镜头，不进入完整合成。

## 状态机

```text
draft
→ reference_analysis_awaiting_files
→ storyboard_awaiting_human
→ keyframes_awaiting_human
→ seedance_handoff_ready
→ seedance_clips_awaiting_human
→ compose_ready
```

参考视频缺失时允许的终态：`reference_analysis_awaiting_files`。  
本轮禁止的状态：`compose_ready`、`rendered`、`published`。
