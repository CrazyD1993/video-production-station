## 视觉检查

- A：单一中央眼区和左右眼墙保持稳定；没有箭头、文字、HUD、第二风眼或完美同心圆。云墙连续变化，需由用户实际播放判断“向上翻卷”是否足够清楚。
- B：暖金色体积层由上至下自然减弱，中央空间逐渐通透；没有硬边光柱、箭头、文字或HUD。需由用户实际播放判断“缓慢下沉”是否足够直观。
- 两个Fast原始结果都附带AAC音轨；最终审核版已无损移除音轨。

## 停止条件

当前停在两段机制镜头人工确认门禁。未经确认，不替换4.05—14.70秒片段，不渲染完整25秒视频，不恢复箭头几何路线。
