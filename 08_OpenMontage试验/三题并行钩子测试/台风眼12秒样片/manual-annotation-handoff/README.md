# 台风眼 25 秒人工标注交接包

本目录用于在剪映中人工定位结构标注。所有标注均为独立、紧边界透明素材，没有预设到 1080×1920 视频坐标，也没有合并进成片。

## 干净底片

- 本地文件：`../output/typhoon-eye-25s-clean-base.mp4`
- 规格：1080×1920、30 fps、H.264、25.000 秒；AAC 48 kHz 双声道
- 保留：B 版旁白、正式字幕、BGM、环境音和原混音
- 删除：结构箭头、结构标签、虚线圆、中心点和结构引线
- Git：视频继续受 `.gitignore` 保护，不提交仓库

## 独立素材

| 编号 | 内容 | SVG 画布 | PNG 像素尺寸 |
|---|---|---:|---:|
| 01 | 左眼墙标签与上升箭头 | 360×900 | 720×1800 |
| 02 | 右眼墙标签与上升箭头 | 360×900 | 720×1800 |
| 03 | 缓慢下沉标签与箭头 | 420×900 | 840×1800 |
| 04 | 虚线圆 | 640×760 | 1280×1520 |
| 05 | 橙色中心点 | 48×48 | 96×96 |
| 06 | 指向中心箭头 | 480×320 | 960×640 |
| 07 | 相对平静标签与引线 | 420×180 | 840×360 |
| 08 | 另一侧眼墙标签 | 420×160 | 840×320 |

SVG 是可编辑主文件；PNG 是剪映直接导入版本，均保留透明背景。素材颜色遵循：蓝色表示眼墙/上升，黄色表示缓慢下沉，橙色表示中心关注点。

## 使用边界

- 不要让软件自动跟踪或自动估计风眼中心。
- 所有位置和缩放由人工根据当时画面判断。
- 不要把多个结构组预先合并成一张全屏贴图。
- 不要增加发光、弹跳、闪烁或科技 HUD 动效。
- 本交接包完成后停止自动渲染，不生成 V4。

具体时间点和人工定位方法见 [剪映人工定位说明.md](./剪映人工定位说明.md)。
