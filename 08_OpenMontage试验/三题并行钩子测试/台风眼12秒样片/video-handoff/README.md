# 台风眼12秒样片 Seedance 手动交接

当前模式为手动Seedance图生视频。Codex不会登录或自动调用Seedance，也不会在三段真实视频回传前用静态图片伪装动态样片。

## 已准备首帧

本地 `frames/` 中包含：

- `TE-S01-first-frame.png`：TE-KF1-A干净首帧，1080×1920。
- `TE-S02-clean-base.png`：TE-KF2-A无箭头、无文字、无标签底图，1080×1920。
- `TE-S03-first-frame.png`：TE-KF3-B干净首帧，1080×1920。

三张首帧均不含“AI视觉重建”“非真实卫星观测”、水印或免责声明。它们保留在本地，不提交GitHub。

## 用户生成步骤

1. 在Seedance中分别上传对应首帧。
2. 使用 `prompts/TE-S01.yaml`、`TE-S02.yaml`、`TE-S03.yaml` 的正向提示词和禁止项。
3. 每段先生成5秒，9:16；不要求模型直接输出3.2秒或4秒。
4. 将结果放入本目录的 `incoming/`：
   - `TE-S01-seedance-v1.mp4`
   - `TE-S02-seedance-v1.mp4`
   - `TE-S03-seedance-v1.mp4`

不要把账号密码、Cookie或平台凭据写入项目。

## 回传后处理

Codex收到三段视频后将：

1. 检查时长、分辨率、帧率、云体稳定、风眼大小和海面运动；
2. 从TE-S01截取3.2秒、TE-S02截取4.8秒、TE-S03截取4秒；
3. 给TE-S02重新叠加独立可控的上升/缓慢下沉路径与结构标签；
4. 合成 `typhoon-eye-12s-visual-review.mp4`，不含配音、字幕、BGM和音效；
5. 视觉版无重大错误后，再生成两版自然女声配音并制作完整包装审片版；
6. 12秒样片通过后直接扩展25秒成片，不新增策划审批。
