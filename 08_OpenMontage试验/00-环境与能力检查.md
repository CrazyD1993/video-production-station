## 4. Seedance 接入判断

OpenMontage 当前源码已包含：

- `video_selector`；
- `seedance_video`（fal.ai）；
- `seedance_replicate`；
- Runway/Higgsfield 的 Seedance 2.0 模型入口；
- `text_to_video`、`image_to_video`、`reference_to_video`；
- 9:16、分辨率、时长、seed、音频等参数；
- 先 fast 低成本试投、锁 seed、再 standard 的迭代策略。

但当前所有 Seedance 网关均未被 registry 识别为可用。因此本试点采用 **模式 B：手动交接**。不得尝试复用网页登录态、Cookie、账号密码或浏览器自动化绕过 API。

## 5. Backlot 与零付费工作流

- Backlot 服务已在本机临时启动并通过健康检查。
- 可在没有真实生产项目时运行模拟项目；也可通过 `init_project()` 创建工作区后显示 script、scene plan、checkpoint、asset manifest 和成本记录。
- Backlot 是只读观察板，故事板门禁由 checkpoint 文件执行。
- 可以只写创意方案、脚本、场景计划、关键帧提示词和审批 checkpoint，不调用生成工具。
- 本轮不在 OpenMontage 内生成资产；桥接目录中的故事板作为审批正文，批准后再建立 OpenMontage project workspace。

## 6. 许可证与仓库集成风险

| 风险 | 本轮控制 |
|---|---|
| AGPL 网络交互条款 | 不部署线上服务，不向第三方提供修改版网络服务 |
| 源码衍生/混合风险 | OpenMontage 保持独立同级仓库，不复制源码进主仓库 |
| 分发义务 | 本轮不分发 OpenMontage 或其修改版 |
| 私有主仓库污染 | 只提交自有桥接文档、清单和提示词，不提交上游源码 |
| API 密钥泄露 | 只允许写入 OpenMontage 本地 `.env`；不写日志、Markdown、GitHub |
| 第三方素材版权 | 不提交参考视频、未授权素材、缓存、生成大文件；素材台账逐项登记 |

结论仅用于本地工程风险控制，不构成法律意见。若未来修改 OpenMontage、对外提供网络服务或分发组合产品，需重新做 AGPL 合规审查。
