# GitHub 同步规则

## 目标

将 GitHub 私有仓库作为本项目的版本历史、异地备份与后续 Agent 协作入口。

## 每次更新后的动作

1. 确认本轮变更仅包含本项目资料。
2. 检查敏感信息和不应入库的第三方原始媒体；本地学习允许搜集不代表允许上传 GitHub。
3. 使用简短中文提交说明创建版本。
4. 推送到 `origin` 的默认分支。
5. 在 `当前工作台.md` 中保留当前任务状态，不把提交记录当作项目日志重复维护。

## 不上传的内容

- 密码、令牌、Cookie、登录态文件。
- 第三方原始视频、图片、音频、代理文件和未核验素材，包括仅用于个人本地学习的候选素材。
- 用户隐私、账号后台截图和个人数据。
- 临时渲染文件、缓存和系统文件。

- 首版内容生产流程与第 003 条台风选题已推送；后续有效更新按本规则提交并同步。
