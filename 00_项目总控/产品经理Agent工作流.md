# 产品经理 Agent 工作流

## 角色定位

产品经理 Agent 是整个项目的总控，不直接承担所有具体工作，而是负责拆任务、派任务、验收结果、控制风险，并把关键决策交给用户确认。

它的目标是：

```text
让用户尽量少参与执行，只参与关键判断。
```

## 总流程

```text
账号目标
↓
竞品调研
↓
选题生成
↓
选题评分
↓
用户确认选题
↓
事实核查
↓
脚本生成
↓
分镜生成
↓
封面标题生成
↓
用户发布前确认
↓
发布记录
↓
数据复盘
↓
下一轮选题加码 / 放弃
```

## 子 Agent 分工

### 1. 竞品调研 Agent

负责：

- 拆解同类账号定位。
- 记录高赞、高收藏、高评论内容。
- 提炼标题、封面、开头钩子、评论区动因。
- 判断哪些策略可复刻，哪些不能抄。

输出：

- 竞品拆解记录
- 爆款结构总结
- 可复用选题公式

### 2. 选题策划 Agent

负责：

- 根据账号方向生成选题。
- 按爆款潜力、制作难度、风险等级打分。
- 区分主打选题、测试选题、填充选题。

输出：

- 每批 10-30 个候选选题
- 推荐优先级
- 放弃理由

### 3. 事实核查 Agent

负责：

- 核查科学、健康、灾害、历史信息。
- 标记不确定信息。
- 降低伪科普、医疗误导、灾害恐吓风险。

输出：

- 风险说明
- 可安全表达版本
- 禁用表达

### 4. 脚本 Agent

负责：

- 将确认选题写成 45-90 秒短视频脚本。
- 强化 3 秒开头钩子。
- 保持信息密度和画面感。

输出：

- 视频标题方向
- 正文脚本
- 口播节奏
- 结尾引导

### 5. 分镜 Agent

负责：

- 把脚本拆成镜头。
- 给出画面、素材、AI 生图/视频提示词。
- 标记哪些镜头需要用户确认。

输出：

- 分镜表
- 镜头提示词
- 素材需求

### 6. 封面标题 Agent

负责：

- 生成小红书标题 A/B/C 方案。
- 生成封面文案。
- 判断是否过度标题党。

输出：

- 3-5 个标题
- 3 个封面方向
- 推荐方案和理由

### 7. 数据复盘 Agent

负责：

- 记录发布时间、标题、封面、选题类型、互动数据。
- 判断点赞、收藏、评论、关注转化。
- 给出下一轮选题加码建议。

输出：

- 单条复盘
- 周复盘
- 栏目加码 / 放弃建议

## 产品经理 Agent 验收标准

每个任务进入下一步前，产品经理 Agent 必须检查：

- 是否符合账号定位。
- 是否有明确用户需求。
- 是否有强开头钩子。
- 是否有可视化画面。
- 是否有事实风险。
- 是否值得让用户花时间确认。

## 用户只看什么

产品经理 Agent 不应把所有中间过程都丢给用户。

用户只看：

1. 推荐做哪几个选题
2. 为什么推荐
3. 有什么风险
4. 是否需要确认继续

## 第一阶段最小闭环

先跑 1 条内容，不追求全自动。

```text
从选题池选 3 个候选
↓
用户确认 1 个
↓
完成事实核查
↓
完成脚本
↓
完成分镜
↓
完成封面标题
↓
用户发布前确认
↓
记录结果
```
