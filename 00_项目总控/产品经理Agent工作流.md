# 产品经理 Agent 工作流

## 角色定位

产品经理 Agent 是整个项目的总控，不直接承担所有具体工作，而是负责拆任务、派任务、验收结果、控制风险，并把关键决策交给用户确认。

它的目标是：

```text
让用户尽量少参与执行，只参与关键判断。
```

## 总流程

```text
账号目标
↓
竞品调研
↓
选题生成
↓
选题评分
↓
用户确认选题
↓
事实核查
↓
脚本生成
↓
导演 Agent：观看设计与视觉证据
↓
动态分镜 Agent：镜头合同与制作方案
↓
素材 / 声音 / 剪辑 Agent：合成初版
↓
冷观众审片 Agent：发布门禁
↓
封面标题生成
↓
用户发布前确认
↓
发布记录
↓
数据复盘
↓
下一轮选题加码 / 放弃
```

## 子 Agent 分工

### 1. 竞品调研 Agent

负责：

- 拆解同类账号定位。
- 记录高赞、高收藏、高评论内容。
- 提炼标题、封面、开头钩子、评论区动因。
- 判断哪些策略可复刻，哪些不能抄。

输出：

- 竞品拆解记录
- 爆款结构总结
- 可复用选题公式

### 2. 选题策划 Agent

负责：

- 根据账号方向生成选题。
- 按爆款潜力、制作难度、风险等级打分。
- 区分主打选题、测试选题、填充选题。

输出：

- 每批 10-30 个候选选题
- 推荐优先级
- 放弃理由

### 3. 事实核查 Agent

负责：

- 核查科学、健康、灾害、历史信息。
- 标记不确定信息。
- 降低伪科普、医疗误导、灾害恐吓风险。

输出：

- 风险说明
- 可安全表达版本
- 禁用表达

### 4. 脚本 Agent

负责：

- 将确认选题写成 45-90 秒短视频脚本。
- 强化 3 秒开头钩子。
- 保持信息密度和画面感。

输出：

- 视频标题方向
- 正文脚本
- 口播节奏
- 结尾引导

### 5. 分镜 Agent

负责：

- 把脚本拆成镜头。
- 给出画面、素材、AI 生图/视频提示词。
- 标记哪些镜头需要用户确认。

输出：

- 分镜表
- 镜头提示词
- 素材需求

### 5A. 导演 Agent（V2 新增）

负责：

- 将脚本改造成有观看动力的视觉叙事，而不是给旁白配文字卡。
- 为每个镜头写清镜头目的、观众看见的动作、视觉证据、下一秒变化和声音提示。
- 控制每 3 秒左右的视觉变化，并把静态卡压到 15% 以下。

验收问题：

1. 前 3 秒的冲突和强主体是什么？
2. 用户为什么会看到第 5 秒？
3. 第 10 秒新增了什么信息或证据？
4. 每 5 秒是否有新的视觉变化？
5. 是否有一个能被记住的视觉证据？

### 5B. 动态分镜 Agent（V2 新增）

负责：

- 把导演设计落成可制作的镜头合同：时长、画面动作、字幕节奏、素材、声音、制作方式、事实与版权风险。
- 优先安排实拍、授权素材、可标注的示意动画和动态图形；避免用静态图片撑时长。

输出：动态分镜、镜头制作方案、素材清单、合成时间线。

### 5C. 声音 Agent（V2 新增）

负责：

- 选择经授权的中文配音、背景音乐、环境音和动作音效。
- 以节奏、停顿和关键动作声服务理解，不用惊吓式音效制造伪紧张。

输出：配音稿、声轨提示表、授权状态表。

### 5D. 冷观众审片 Agent（V2 新增）

负责：

- 以第一次刷到的陌生用户视角评估停留、好奇、划走点、静音理解和记忆点。
- 给出“通过 / 有条件通过 / 打回”结论；预审结论必须标明它不是实际用户数据。

输出：冷观众审片报告、必须修改项、发布风险。

### 6. 封面标题 Agent

负责：

- 生成小红书标题 A/B/C 方案。
- 生成封面文案。
- 判断是否过度标题党。

输出：

- 3-5 个标题
- 3 个封面方向
- 推荐方案和理由

### 7. 数据复盘 Agent

负责：

- 记录发布时间、标题、封面、选题类型、互动数据。
- 判断点赞、收藏、评论、关注转化。
- 给出下一轮选题加码建议。

输出：

- 单条复盘
- 周复盘
- 栏目加码 / 放弃建议

## 产品经理 Agent 验收标准

每个任务进入下一步前，产品经理 Agent 必须检查：

- 是否符合账号定位。
- 是否有明确用户需求。
- 是否有强开头钩子。
- 是否有可视化画面。
- 是否有可观看的动作与视觉证据，而不是文字替代画面。
- 是否有事实风险。
- 是否值得让用户花时间确认。

## 用户只看什么

产品经理 Agent 不应把所有中间过程都丢给用户。

用户只看：

1. 推荐做哪几个选题
2. 为什么推荐
3. 有什么风险
4. 是否需要确认继续

## 第一阶段最小闭环

先跑 1 条内容，不追求全自动。

```text
从选题池选 3 个候选
↓
用户确认 1 个
↓
完成事实核查
↓
完成脚本
↓
完成分镜
↓
完成封面标题
↓
用户发布前确认
↓
记录结果
```
