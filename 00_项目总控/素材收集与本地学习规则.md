# 素材收集与本地学习规则

## 默认用途

本项目的素材搜索、下载、整理、分析、素材板和内部粗剪，默认用于用户个人本地学习与研究。

在这一用途下，公开可访问的第三方视频、图片、音频、新闻、纪录片、社交媒体内容、机构资料和其他参考素材均可进入本地候选池，不要求先取得商业许可、书面授权或明确的可商用声明。

## 最大开放搜集

- Agent 可以主动搜索、下载、分类、截帧、转写、分析和比较公开可访问的素材。
- 权利状态未知的素材可以进入本地素材板、测试剪辑和非公开审核样片。
- 授权状态不得成为搜索、下载或内部试剪的前置门禁。
- 素材台账可以将此类资产标记为 `个人本地学习 / 权利待核验`，但不得因此停止搜集。
- 对竞品、新闻、影视、纪录片、机构媒体和其他创作者内容，可以先收集并分析，再根据未来用途决定是否寻找授权或替换。

## 无水印原版策略

- 优先寻找无平台水印、无烧录字幕、无二次搬运标识的原始发布版本、官方媒体库版本或素材母版。
- 带水印的候选仍可保存用于定位原作者、反向寻找原始页面和内部分析。
- 不使用去水印、内容修复、遮挡或刻意裁切等方式，主动删除或改变已有水印、作者标识、版权声明或其他权利管理信息。
- 如果只找到带水印版本，应继续寻找原始来源、同源干净版本或功能相同的替代素材。

## 获取方式边界

- 只使用正常公开访问、平台允许下载或用户账号本来有权访问的获取方式。
- 不绕过付费墙、订阅限制、DRM、加密、验证码、账号权限或平台访问控制。
- 不提取、记录或提交用户的 Cookie、密码、令牌和其他登录凭据。

## 来源记录

能够识别时，尽量保留以下最小信息：

- 原始链接；
- 平台；
- 作者或发布机构；
- 下载日期；
- 本地用途或对应镜头。

来源记录用于复查、寻找无水印原版、避免重复搜索以及未来可能的授权联系，不作为个人本地搜集的门禁。暂时找不到原始出处时，可以标记 `来源待追溯` 后继续内部工作。

## 本地保存与 GitHub

- 第三方原始视频、图片、音频、缓存、代理文件和未核验素材只保存在本地素材目录。
- GitHub 只保存文字规则、来源链接、分析结论、镜头合同和不包含第三方原始媒体的台账。
- 不把 Cookie、账号信息、个人数据或其他敏感信息写入素材台账、中继文档或 GitHub。

## 用途变化

本规则不自动覆盖以下用途：

- 公开发布；
- 商业使用；
- 广告投放；
- 向第三方分发；
- 出售素材或含素材的产品。

当用户明确把任务切换到上述用途时，Agent 应重新核验实际进入交付物的素材，包括许可范围、署名要求、肖像、音乐、平台条款和其他必要条件。用途切换只影响对外交付门禁，不追溯限制此前的个人本地搜集与学习。
