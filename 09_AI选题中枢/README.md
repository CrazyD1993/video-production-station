# 选题罗盘

为个人女性 AI / 商业真人 IP 定制的私人选题中枢。

## 核心定位

账号不是“AI 工具老师”，而是：

> 真正拿 AI 完成项目、敢展示失败并给出独立判断的女性实验者。

题库只保留能够强化以下至少一个角色的内容：

- 实验者：有真实过程、成片、录屏、工时或失败版本；
- 翻译者：能把 AI 与商业问题讲成人话；
- 审片人：能判断工具适合谁、不能做什么、是否值得投入。

## 工作流

```text
今日雷达
→ 候选池
→ 重点观察
→ 已选待拍
→ 已经完成
→ 归档
```

系统不会让每日自动任务直接把题目放入“已选待拍”。自动任务只负责发现和收录，最终选择权保留给用户。

## 评分

满分 100，低于 70 分原则上不进入候选池：

| 维度 | 分值 |
|---|---:|
| 用户痛感 / 好奇 | 25 |
| 一手证据 | 25 |
| 人设增量 | 20 |
| 可复用性 | 15 |
| 时效与讨论度 | 10 |
| 制作可行性 | 5 |

## 每日雷达规则

每天搜索 YouTube、小红书、抖音、X、B站及可信 AI / 商业来源，新增 5—8 条候选。优先：

- 女性真人 IP 可解释、可口播的题；
- AI 与真实工作、内容生产、小生意、职业变化的交叉；
- 有公开来源和一手验证路径；
- 手机固定机位 + 录屏即可完成；
- 能发展为连续栏目。

主动排除：

- 只有工具发布，没有普通人场景；
- 夸张收益、恐惧营销或不可核验结论；
- 纯搬运热点；
- 必须依赖重制作才能成立；
- 与题库已有内容高度重复。
