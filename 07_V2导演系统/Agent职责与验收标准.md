# V2 Agent 职责与验收标准

## 产品经理 Agent

维护总排期和门禁，只把“选题确认、V2 脚本/动态分镜确认、发布前确认”交给用户。任何 Agent 的交付未达到标准时，自动退回上一环节，不把半成品交给用户判断。

## 导演 Agent

每条输出必须包含：3 秒钩子、视觉证据、镜头变化表、记忆画面、静态画面占比估算和不可用画面清单。

**验收：** 每句重要旁白都能回答“观众正在看到什么”；没有“旁白讲动作，画面只写同一句话”的镜头。

## 动态分镜 Agent

按镜头合同实现：镜头目的、动作、视觉变化、素材来源、制作方法、字幕、声音、风险、备选方案。

**验收：** 任一镜头缺少视觉证据、素材来源或版权状态，不进入合成。

## 声音 Agent

声音分为配音、音乐、环境、动作、停顿五层，且所有音源可追溯。

**验收：** 静音时仍能理解；有声时关键声效强化动作而非掩盖信息。

## 冷观众审片 Agent

使用首次观看视角，在 0-3 秒、3-10 秒、每 10 秒和结尾分别评分，并区分“预审推断”与“真实发布数据”。

**打回条件：** 前 3 秒没有明确问题；10 秒内没有新证据；静音无法理解；存在超过 3 秒无新信息的静态段；结尾没有可复述观点。
