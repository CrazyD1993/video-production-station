# 003 V2 素材需求与授权台账

| 素材 | 用途 | 获取优先级 | 授权状态 | 风险提示 |
|---|---|---|---|---|
| 双窗、裂纹、碎片轨迹 | 开头视觉证据 | 自制动态图形 | 自制 | 标注“结构示意” |
| 风压、受力箭头、窗框结构 | 因果解释 | 自制动态图形 | 自制 | 不标注未经验证数值 |
| 窗户锁扣、拉窗帘 | 行动演示 | 自拍 | 用户自有 | 避免拍到住址与外部隐私 |
| 收回花盆、晾衣架 | 行动演示 | 自拍 | 用户自有 | 不拍人脸与邻居信息 |
| 抽象官方预警界面 | 转移提醒 | 自制 UI | 自制 | 不伪造真实预警，不出现具体城市 |
| 雨声、锁扣、窗帘滑轨 | 声音层 | 可商用音效库 / 自录 | 制作前登记 | 不使用新闻现场原声 |

## 采购与替代原则

素材缺失时优先缩短或重写镜头，不以来源不明的新闻片段填充。若采用第三方素材，记录链接、许可类型、下载日期、使用范围与署名要求。
