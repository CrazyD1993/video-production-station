# 003 V2 脚本：台风来前，窗户贴米字胶带，保护的到底是什么？

## 成片定位

- 建议时长：68 秒。
- 一句话结论：台风天贴米字胶带，主要是在玻璃已经破裂时辅助减少碎片飞散，不会把普通窗户变成抗风窗。
- 视觉承诺：观众在前 10 秒看懂“同样破裂，碎片状态不同”；随后看懂胶带挡不住什么，以及真正优先要做什么。

## 旁白

| 时间 | 旁白 |
|---|---|
| 0-3 秒 | 同样一块玻璃破了，贴没贴胶带，差别可能不在它会不会碎。 |
| 3-8 秒 | 而在碎掉以后，碎片会不会往屋里飞。 |
| 8-14 秒 | 米字胶带更像给已经裂开的玻璃多一层约束，不是给窗户加了一层盔甲。 |
| 14-22 秒 | 风压会让整块玻璃和窗框一起受力，胶带并不能替它们变结实。 |
| 22-30 秒 | 真有杂物撞上来，决定会不会破的，是玻璃、窗框和外部防护，不是胶带。 |
| 30-37 秒 | 窗框本身松动，贴得再整齐，也留不住一扇失去固定的窗。 |
| 37-48 秒 | 真正优先做的，是关紧检查门窗，把阳台和窗台会飞的东西收进来。 |
| 48-56 秒 | 拉好窗帘，风雨最强时别靠近玻璃；当地要求转移，就马上转移。 |
| 56-64 秒 | 所以，如果当地提示建议贴，可以贴；但把它当成辅助，不要当成加固。 |
| 64-68 秒 | 记住这句：胶带管碎片，不管风压。 |

## 表达边界

- “碎片状态不同”仅以示意或受控演示呈现，屏幕标注“结构示意，不代表实际玻璃强度”。
- 不说“贴了必然减少伤害”，改用“辅助减少碎片飞散风险”。
- 所有应急动作以当地气象和应急部门实时通知为准。
