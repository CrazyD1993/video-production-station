# 003 V2 前 14 秒 R2：两版开头方案

## A. 真人场景叙事版（最终方向）

```text
真实雨窗 + 贴胶带动作重演
→ “很多人第一件事就是贴胶带”
→ 突然反转：“它救不了你的窗户”
→ 结构示意只解释“可能约束部分碎片”
→ 悬念：“真正该防的是下一阵风”
```

| 时间 | 画面 | 旁白 / 字幕 | 陌生用户为什么停留 |
|---|---|---|---|
| 0-4.7 秒 | 真实雨窗，米字胶带动作快速出现 | `台风预警一来，很多人第一件事，就是给窗户贴满胶带。` | 是熟悉的家庭动作，雨窗建立紧迫感 |
| 4.7-8.7 秒 | 动作突然停住，玻璃上出现短促反转 | `但先别急着把它当护身符。` | 打断既有常识，观众想知道为什么 |
| 8.7-14 秒 | 真实雨窗上叠加最少量的裂纹结构示意 | `它不能让玻璃变成防台风玻璃，更不能保证窗户不破。` | 明确推翻“贴了就安全”的错觉 |

**优势：** 先有生活代入，再给反转；动画只在需要解释时出现。  
**限制：** 当前没有经授权的真人手部贴胶带视频。本样片使用真实雨窗素材加导演化动作重演，不能称为真实演示。

## B. 纯动画反差版

```text
胶带 X 迅速贴上示意玻璃
→ 同一刻裂纹出现
→ “贴了，也会碎？”
→ 以虚线解释部分碎片可能被约束
```

**优势：** 科学边界最容易控制，素材可完全自制。  
**短板：** 与上一版的核心气质接近，仍可能被观众感知为“动态图解科普”，不符合本次要提升真实感和情绪停留的目标。

## 最终选择

选择 **A 真人场景叙事版**。理由不是它更“真实”，而是它先让观众代入自己家窗边的那个动作，再利用反转把知识解释变成一个待解的问题。结构示意退到第二位置，只负责说明“胶带不等于加固”。
