# 与 V1 前 14 秒差异说明

| 维度 | V1 前 14 秒 | V2 前 14 秒原型 |
|---|---|---|
| 开头 | 雨窗氛围与标题，问题出现较慢 | 双窗同步裂纹，第一帧就有冲突 |
| 画面角色 | 画面主要承载文字 | 画面展示“讨论的是碎片状态，不是防破窗”的结构关系 |
| 证据表达 | 缺少可辨认的因果画面 | 明确是 `illustrative_simulation`，全程标注“结构示意” |
| 风险控制 | 容易被误读为胶带有确定防护作用 | 使用“可能辅助约束部分碎片”，右侧只呈现虚线和不确定性 |
| 字幕 | 静态信息页 | 分段逐句字幕，关键词只承担当前结论 |
| 声音 | 配音与画面关系较弱 | 裂响、短停顿和旁白绑定到裂纹、碎片、结构拆分变化 |
| 工程 | FFmpeg + SVG 静态图 | Remotion 动态组件渲染；FFmpeg 仅做最终封装 |
