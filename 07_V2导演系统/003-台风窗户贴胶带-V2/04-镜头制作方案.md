# 003 V2 镜头制作方案

| 模块 | 制作方案 | 为什么这样做 | 验收点 |
|---|---|---|---|
| 双窗破裂对比 | 使用 Remotion 绘制统一尺寸的两块“示意窗”，同一冲击帧触发不同碎片轨迹 | 可控制同条件，避免制造真实灾害或不安全实验 | 明示“结构示意”；不暗示真实强度数据 |
| 风压 / 撞击 / 窗框 | 用简洁矢量受力动画与自制锁扣实拍组合 | 分别解释三种失败路径，避免一句话带过 | 箭头、受力点与窗框变化同步 |
| 四项动作 | 自拍家庭安全动作；人物不露脸亦可 | 画面直接提供行动信息，替代清单卡 | 每个动作在 1 秒内可辨认 |
| 字幕 | Whisper 对齐初始时间轴，Remotion 输出逐句字幕；关键词仅强调“碎片、风压、窗框、转移” | 保证静音理解，不把全部旁白堆在屏上 | 单行优先，避开核心动作区 |
| 合成 | 用 Remotion 导出动态图形片段，再用 FFmpeg 组合实拍、音轨与最终文件 | 保留可复用组件，同时让实拍承担生活感 | 9:16、1080x1920、逐帧审看关键镜头 |

## 不能伪造的内容

- 不用未经测试的动画宣称胶带的实际防护比例。
- 不将示意撞击伪装成真实台风实验。
- 不用真实受灾家庭、媒体新闻和带台标的事故画面。
