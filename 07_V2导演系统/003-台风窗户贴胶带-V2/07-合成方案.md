# 003 V2 合成方案

## 时间线层级

```text
底层：自制 / 授权的实拍环境画面
中层：Remotion 动态结构示意、逐句字幕、关键词强调
上层：受力箭头、风险标签、短结论
声音：配音 → 环境 → 动作音效 → 背景音乐
```

## 制作顺序

1. 锁定 V2 脚本和动态分镜，先出 0-14 秒双窗证明镜头样片。
2. 建立 Remotion 的 `WindowComparison`、`ForceDiagram`、`SentenceCaption` 三个可复用组件。
3. 自拍锁窗、收纳、拉帘和离开窗边的动作镜头；逐项核验隐私与画面可读性。
4. 录制或生成授权配音，使用 Whisper 生成初始逐句时间轴，再人工校正关键词停顿。
5. 合成 68 秒初版，检查静态画面比例、字幕安全区、声音峰值与示意标签。
6. 先过冷观众审片，再提交用户“成片初版确认”。

## 交付文件

- `导演分镜.md`、`素材台账.md`、`声音提示表.md`。
- 可复用 Remotion 组件与渲染配置。
- 1080x1920 主成片、无字幕审核版、字幕稿、授权台账。
