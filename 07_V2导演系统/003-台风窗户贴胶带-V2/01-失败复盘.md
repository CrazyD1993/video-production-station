# 003 V1 失败复盘

## 定位结论

V1 是“技术验证版”，证明了竖屏输出、配音和合成可运行；它不具备发布版需要的观看动力与视觉叙事。

## 具体失败点

| V1 现象 | 为什么影响观看 | V2 改法 |
|---|---|---|
| 大段静态信息卡与 SVG 文字页 | 旁白在推进，画面没有发生任何事，像在看 PPT | 用“两块窗玻璃的同条件对比”建立视觉证据；卡片仅在结尾归纳 |
| 旁白说“挡不住风压、飞来物、松动窗框”，画面只出现对应文字 | 用户被告知结论，却没看见因果 | 用标注为“结构示意”的动态受力、撞击和窗框晃动解释三种失效路径 |
| 开头雨窗氛围先于冲突出现 | 冷观众没有立即知道问题的反差 | 首帧直接出现“同样破裂、碎片走向不同”的对比动作 |
| 配音、雨声、BGM 与动作关系弱 | 声音没有帮助节奏或理解 | 将裂响、撞击、锁扣、窗帘滑轨等声音绑定到镜头动作，结论前留停顿 |
| 仅有制作完成检查，没有陌生用户视角 | 容易把“内容正确”误判为“视频可发” | 增加冷观众预审，明确每段的继续理由与划走风险 |

## V2 不沿用的做法

- 不覆盖或修改 V1 成片。
- 不拿事故新闻片段当“真实证据”。
- 不用文字卡代替受力、碎裂、收纳和远离窗边的动作。
- 不把胶带描述成加固方案或防破窗承诺。
