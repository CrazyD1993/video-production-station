# 视频制作站 V2 升级方案

## 目标

V1 已证明“能生成一条竖屏视频”；V2 要证明“视频值得陌生用户停下来继续看”。系统从自动内容拼装升级为 AI 导演驱动的生产链。

## 新流程与门禁

```text
产品经理 Agent
→ 选题 → 事实核查 → 编剧
→ 导演（观看动力、视觉证据）
→ 动态分镜（镜头合同）
→ 素材 / 声音 / 剪辑
→ 冷观众审片
→ 用户发布前确认 → 发布复盘
```

| 门禁 | 通过条件 | 不通过时处理 |
|---|---|---|
| 导演门禁 | 前 3 秒有冲突；每约 3 秒有变化；至少一条视觉证据；静态卡不超过 15% | 回到脚本或导演设计，不开始找素材 |
| 制作门禁 | 每句重要旁白均有对应画面动作；素材授权和事实标签完整 | 替换镜头或改写表达 |
| 冷观众门禁 | 静音也能理解核心；无明显划走点；能复述一个观点 | 打回具体时间段重剪 |

## 工具融入判断

| 工具 | 放入系统的位置 | 应吸收的能力 | 这阶段的决定 |
|---|---|---|---|
| [OpenMontage](https://github.com/calesthio/OpenMontage) | 编排层参考 | 多 Agent 流水线、任务清单、可恢复步骤 | 只借鉴流程，不复制整套代码 |
| [Remotion](https://github.com/remotion-dev/remotion) | V2 主动态图形渲染层 | 时间线、逐句字幕、动态拆解、地图和可复用组件 | 最高优先级，下一制作阶段做最小验证 |
| [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) | 可替换配音服务 | 高质量中文 TTS、经同意的声音克隆 | 暂不安装；先设“声音提供方适配层”和授权台账 |
| [Manim](https://github.com/ManimCommunity/manim) | 解释动画服务 | 结构、过程、科学概念的精确可视化 | 只用于少量示意动画，不能伪装成真实实验 |
| [Whisper](https://github.com/openai/whisper) | 字幕校验与时间轴 | 语音转写、对齐、成片字幕核验 | 下一制作阶段与逐句字幕联调 |

## 实施顺序

1. 本次：固化角色、门禁、模板，并完成第 003 条 V2 审核包。
2. 下次制作前：为 Remotion 建立一个 9:16 动态镜头原型，验证字幕、图形和时间线。
3. 再接入声音与字幕适配层；每个提供方都保留来源、许可和回退方案。
4. 用第 003 条 V2 做首个完整验证，不覆盖 V1 成片。

## 不做的事

- 不把转场、BGM 或色彩调整当成导演升级。
- 不用新闻事故片段充当视觉证据。
- 不用未经授权的声音、新闻画面或下载素材。
- 不让一张静态卡承担整段叙事。
